# Hacker House Goa ID Card Generator (IDCARD-HHG)

A modern, high-performance, client-side ID card generator and branding suite built for Hacker House Goa. Users can seamlessly upload photos, input details, customize titles, preview a fully responsive badge in real-time, and instantly publish shareable Open Graph (OG) assets paired with direct X (Twitter) integration.

---

## 🚀 Features

* **100% Client-Side Rasterization:** Renders high-resolution brand kit cards straight in the browser.
* **Auto-Image Conversion:** Automatically converts HEIF/HEIC files to JPEG on the fly prior to cropping.
* **Vercel Blob Integration:** Securely uploads rasterized badges to Vercel Blob storage with deterministic path resolution for instant social media sharing links.
* **Dynamic OG Cards:** Leverages unique share IDs (`/s/[id]`) to generate permanent, shareable social preview cards.
* **Responsive Styling:** Crafted with Tailwind CSS for a sleek, dark-themed developer workspace aesthetic.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Storage & Hosting:** Vercel Blob, Vercel Deployment
* **Language:** TypeScript
